## Topics / Keywords
`past-in-a-minute` `video-studio` `offline` `remotion` `piper-tts` `youtube-shorts` `history` `javascript` `custom-automation`

## What it does
1. Loads episode data (Hook / Fact / Twist / Reflection / CTA) from CSV, form, or Google Sheet
2. Local dashboard with status checklist: Draft → Script Ready → Voice Ready → Video Rendered → Uploaded
3. Free offline Piper TTS for voice-over
4. Remotion (React) renders final 9:16 portrait `.mp4` with branding
5. Manual upload only (as requested)
